# Privacy Policy Page for GitHub Pages

## What I'll create

**`docs/index.html`** — a single, self-contained static page (inline CSS, no build step, no external assets) that GitHub Pages can serve directly. It will be mobile-friendly and use a dark, haunted-house–flavored theme to match the app. I'll also add **`docs/.nojekyll`** (empty file) so GitHub Pages serves the folder as-is without Jekyll processing.

## Policy content (based on how the app actually behaves)

- **App identity**: Scream O' Clock (com.zieuro.screamoclock / com.zieuro.scream_o_clock), developer Zieuro.
- **No accounts, no tracking**: no sign-in, no analytics, no ads, no profiling; nothing collected to identify anyone.
- **On-device storage only**: display settings, selected role, today's schedule, and armed-alarm state stored locally (AsyncStorage); a random anonymous UUID kept in secure storage for feedback — deleted by uninstalling or clearing app data.
- **Schedule data**: read-only, anonymous fetches of slot assignments from Supabase; no identifiers sent, no writes.
- **Notifications**: notification permission, exact alarms, and run-at-startup rescheduling — all processed on-device.
- **Feedback (Harken)**: only when the user submits feedback — the typed message plus optional photo/file attachments (camera/photo-library access used solely for attaching), tagged with the anonymous UUID, sent to Harken's API.
- **Third-party links**: Ko-fi donation page.
- **Standard sections**: children's privacy, security, changes to the policy, effective date (September 4, 2026), and contact: **zieuro.dev@gmail.com**.
